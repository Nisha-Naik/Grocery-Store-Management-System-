# 🛒 Grocery Store Management System

The Grocery Store Management System is a web-based application designed to simplify daily store operations such as product management, stock monitoring, billing, supplier handling, and sales tracking.  
The system provides a clean, intuitive interface and improves store efficiency by digitizing manual tasks.

---

## 📌 Project Overview

This system helps store owners and managers efficiently handle:

- 📦 Product inventory  
- 🛒 Customer billing  
- 🚚 Supplier management  
- 📊 Sales reporting  
- 🔔 Low-stock alerts  
- 💾 Secure data storage  

Built using **PHP**, **MySQL**, **HTML/CSS**, and **XAMPP**, it is suitable for small and medium-sized grocery shops.

---

## 💡 Key Highlights

###  1. Inventory Management  
Store owners can add, update, delete, and view products with details such as:  
- Product name  
- Category  
- Cost & selling price  
- Quantity in stock  
- Expiry date  

###  2. Supplier Management  
Manage supplier information with:  
- Supplier name  
- Contact details  
- Product supplied  
- Purchase history  

###  3. Billing System  
A fast and simple billing module allows:  
- Adding items to cart  
- Auto-calculated totals  
- GST/tax calculations  
- Print and save invoice  

###  4. Low Stock & Expiry Alerts  
Automatic notifications for:  
- Items with low quantity  
- Products nearing expiry  

This helps maintain stock balance and avoid losses.

###  5. Secure Role-Based Access  
- Admin login  
- Staff login  
- Permission-based dashboard

## ⚙️ Setup Instructions

### 1️⃣ Clone Repository
```bash
git clone https://github.com/your-github-username/grocery-store-system.git
cd grocery-store-system
```

### 2️⃣ Start XAMPP Server  
- Start **Apache**  
- Start **MySQL**

### 3️⃣ Import Database  
1. Open phpMyAdmin  
2. Create a database named:  
```
grocery_db
```
3. Import the SQL file located in `/database/grocery_db.sql`

### 4️⃣ Run Application  
Place the folder inside:
```
C:\xampp\htdocs\
```

Open the browser and visit:
```
http://localhost/grocery-store-system
```
